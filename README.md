# Plateforme de suivi de projets etudiants

Application web Laravel + Vue pour la gestion des projets, taches, groupes, livrables et utilisateurs.

## Fonctionnalites

- Authentification et gestion des roles
- Suivi des projets, taches et livrables
- Gestion des groupes et des membres
- Tableau de bord avec indicateurs et graphiques
- Interface multilingue
